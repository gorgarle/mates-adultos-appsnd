Cómo se forman los grupos

Elige una base y usa los botones de cada recuadro para añadir o quitar unidades sueltas, cajas o camiones. Cuando se llene la bandeja de unidades sueltas, se forma una caja. Cuando se llenen las cajas, se forma un camión. En la base 60 (el reloj), las unidades son segundos, minutos y horas.
